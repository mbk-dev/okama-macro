# API reference

The public package API consists of `get()` and `list_series()`. Import both
directly from `okama_macro`:

```python
from okama_macro import get, list_series
```

::: okama_macro.registry.get
    options:
      show_root_heading: true
      separate_signature: true

::: okama_macro.registry.list_series
    options:
      show_root_heading: true
      separate_signature: true
